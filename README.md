# FC Mobile Squad Reviewer
Build your XI and get a review: average OVR, line strength, weak links, out-of-position players, balance, club links.

Run: double-click START.bat (needs Python 3), or just open index.html.

## Important
EA has no public API for FC Mobile squads or user IDs, and unofficial endpoints can't be verified, so none are used. Squads are saved in your browser under any name or ID you type.
Import your own players with a CSV (name,position,ovr,club); see players-sample.csv.
Not affiliated with EA.
